# 回測方法與限制

## 價格與股息

- 行情以 `auto_adjust=False`、`actions=True`、`repair=True` 取得。每次額外下載
  400 日前置與 7 日以上後置資料，提供 yfinance 足夠脈絡修復錯誤除息日、重複／
  單位錯誤股利、漏調整拆股與損壞價格；完成後才裁切成使用者要求區間。
- 總報酬使用 Yahoo Finance 調整後收盤價變動。一般收盤價用於股利收益率的前一
  交易日分母；缺少調整後價格時，才以價格報酬加現金配發重建總報酬。
- 現金配發包含普通／特別股利與基金資本利得配發。配發報酬為除息日每股配發除以
  前一有效收盤價，不設任意 50% 上限，以免截斷特別股利或清算型配發。
- 報酬採加法分解：

$$
r_{total,t}=r_{price,t}+y_{distribution,t}
$$

  因此「不再投入股息」在除息當日不會平白增加或減少資產；差異只會來自往後留在
  現金中的配發不再參與標的漲跌。
- 配發以除息日認列，因 Yahoo/yfinance 歷史資料沒有一致可靠的實際付款日。金額為
  稅前總額，未模擬預扣稅。
- 引擎以資產價值而非股數運算，拆股與反向拆股本身不產生損益。Yahoo 修復後若仍
  出現與明確拆股比例相符的殘留價格跳變，僅在校正後單日變動落在保守範圍內才修正，
  並在 API warning 與資產稽核欄位標示。
- 假設可交易零股，忽略買賣價差、滑價與稅負；使用者設定的交易成本只套用在再平衡成交金額。

## 日期與共同期間

所有資產與基準使用共同有資料的交集期間。資產成立日晚於要求開始日，或資料早於要求結束日停止時，API 會調整有效期間並回傳警告。關閉「納入今年迄今」時，若結束日位於目前年度，結束日會移到上一年的 12 月 31 日。

投資組合淨值、時間加權報酬與回撤均在每個可取得的日估值點計算；最大回撤、波動、
VaR、CVaR、Alpha 與 Beta 也都使用完整日序列。API 與圖表預設回傳每日點位。使用者若
改選每週或每月，只會縮減傳送與顯示的曲線點位，不會把底層指標改成週或月計算。
週末或所有相關市場均無新行情的日期不會虛構重複點位。

## 幣別換算

本站固定以新台幣（TWD）作為基準幣別。每個標的先讀取 Yahoo Finance 實際回傳的
報價幣別，再換成 TWD；不以代碼尾碼猜測正式計算幣別。若實際報價幣別或所需匯率
無法驗證，該次回測會明確失敗，不會默認為 USD 或沿用可能錯誤的匯率。

資產報酬按日換算：

$$
1+r_{base,t}=(1+r_{asset,t})(1+r_{FX,t})
$$

其中 $r_{FX,t}$ 是一單位資產幣別換成 TWD 的匯率報酬。系統使用資產交易日與匯率
報價日的聯集：即使某國股市休市，只要當日匯率有變動，該外幣部位仍會在同一天反映
台幣價值變化。非同步交易日使用最近可得匯率水準；若 Yahoo Finance 找不到直接交叉
匯率，系統會嘗試反向報價。

系統先對齊「匯率水準」再計算區間報酬，不會把假日前最後一個匯率日報酬重複套用。
現金配發按當期匯率換算，並維持下列恆等式：

$$
r_{total,base,t}=r_{price,base,t}+y_{distribution,base,t}
$$

API 回應頂層的 `base_currency` 永遠為 `TWD`；`assets[].currency` 則保留各標的原始
報價幣別，供使用者稽核換算來源。初始金額、期末金額、現金流、收入與所有組合價值
欄位均為 TWD。

## 企業行動稽核

每項資產的 API metadata 會回傳普通／特別股利事件數、資本利得配發事件數、拆併股
事件數、yfinance 修復列數與本站額外拆股校正數。這些欄位讓異常績效可回溯至原始
企業行動，而不是用報酬率截尾或靜默忽略。

## 現金流與時間加權報酬

投入與提款會改變資產餘額，但從每日策略報酬中排除，因此時間加權報酬不受外部現金流大小影響：

$$
r_t=\frac{V_t-CF_t}{V_{t-1}}-1
$$

資金加權報酬使用含日期的 XIRR 數值解。若現金流沒有可解的正負號組合，結果會回傳空值。

## 再平衡與交易成本

- 固定頻率可選每月、每季、每半年、每年或不再平衡。
- 偏離門檻表示任一資產與目標權重的絕對差達門檻時觸發。
- 交易成本為成交名目金額乘以基點設定，會直接由組合權益扣除。
- 報表分別列出再平衡次數與累積交易成本。

## 槓桿

- 固定倍數：再平衡時維持指定總曝險／權益倍數。
- 固定借款：初始與再平衡時維持指定借款金額。
- 借款利息按 365.2425 日線性計息並每日扣除。
- 權益／總曝險低於維持率時視為追繳保證金，組合清算並停止交易。

## 績效指標

| 指標 | 定義 |
|---|---|
| 累積報酬 | 最終時間加權指數減 1 |
| CAGR | 依實際經過日數年化的複合報酬 |
| 年化波動 | 每日報酬樣本標準差乘以 $\sqrt{252}$ |
| Sharpe | 年化超額報酬除以年化波動 |
| Sortino | 年化超額報酬除以下檔偏差 |
| 最大回撤 | 報酬指數相對歷史高點的最深跌幅 |
| Calmar | CAGR 除以最大回撤絕對值 |
| VaR / CVaR | 每日歷史分配的 5% 分位數與尾端平均 |
| Beta / Alpha | 與基準日報酬的 OLS 關係 |

## 實質報酬

啟用後，以 FRED `CPIAUCSL` 美國都市消費者物價指數將時間加權報酬折算為實質報酬：

$$
I_{real,t}=\frac{I_{nominal,t}}{CPI_t/CPI_0}
$$

目前使用美國 CPI，因此 TWD 結果會附上明確警告。這代表「相對美國消費籃子的購買力」，不等於台灣本地 CPI 實質報酬。

## 進階分析

- Fama–French：以 Kenneth French 月資料估計五因子加動能回歸，至少需要 24 個重疊月份，僅提供 USD 基準。
- 風格分析：以六檔美股 ETF 作為大型／中型／小型與價值／成長代理，係數限制為非負後正規化；這不是持股式 Morningstar Style Box。
- 市場環境：多空以基準十個月移動平均分類；波動以滾動十二月波動中位數分類。
- 通膨與景氣：使用 FRED CPI 與實質 GDP，需設定免費 FRED API key。

## 主要限制

1. Yahoo Finance 與 yfinance 適用於個人研究，資料可能延遲、缺漏或事後修正。
2. 回測沒有模擬流動性、成交衝擊、稅負、基金費用率與預扣稅。
3. 現存標的資料帶有存活者偏誤，退市證券不一定可取得。
4. 拆分／反向拆分以可持有零股處理，不模擬券商對反向拆股零碎股的現金補償。股票
   分拆、認股權、合併換股、代碼變更與退市清算若未反映在 Yahoo 調整後價格，仍需
   個案核對。
5. 代理 ETF、因子與總經資料的發布時間未用於交易訊號，因此不可把環境分析解讀為可即時交易策略。
6. 歷史績效不代表未來結果；本站不提供投資建議。
