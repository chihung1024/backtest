# 回測方法與限制

## 價格與股息

- 總報酬使用 Yahoo Finance 的調整後收盤價變動。
- 不再投入股息時，價格報酬由總報酬扣除估算股息報酬，現金股息保留在組合現金中。
- 股息收入以除息日股息除以前一交易日收盤價估算；資料修正或公司行動可能使歷史值改變。
- 假設可交易零股，忽略買賣價差、滑價與稅負；使用者設定的交易成本只套用在再平衡成交金額。

## 日期與共同期間

所有資產與基準使用共同有資料的交集期間。資產成立日晚於要求開始日，或資料早於要求結束日停止時，API 會調整有效期間並回傳警告。關閉「納入今年迄今」時，若結束日位於目前年度，結束日會移到上一年的 12 月 31 日。

## 幣別換算

資產報酬先換成指定基準幣別：

$$
1+r_{base,t}=(1+r_{asset,t})(1+r_{FX,t})
$$

其中 $r_{FX,t}$ 是一單位資產幣別換成基準幣別的匯率報酬。非同步交易日使用最近可得匯率；若 Yahoo Finance 找不到直接交叉匯率，系統會嘗試反向報價。

## 現金流與時間加權報酬

投入與提款會改變資產餘額，但從每日策略報酬中排除，因此時間加權報酬不受外部現金流大小影響：

$$
r_t=\frac{V_t-CF_t}{V_{t-1}}-1
$$

資金加權報酬使用含日期的 XIRR 數值解。若現金流沒有可解的正負號組合，結果會回傳空值。

## 再平衡與交易成本

- 固定頻率可選每月、每季、每半年、每年或不再平衡。
- 偏離門檻表示任一資產與目標權重的絕對差達門檻時觸發。
- 交易成本為成交名目金額乘以基點設定，會直接由組合權益扣除。
- 報表分別列出再平衡次數與累積交易成本。

## 槓桿

- 固定倍數：再平衡時維持指定總曝險／權益倍數。
- 固定借款：初始與再平衡時維持指定借款金額。
- 借款利息按 365.2425 日線性計息並每日扣除。
- 權益／總曝險低於維持率時視為追繳保證金，組合清算並停止交易。

## 績效指標

| 指標 | 定義 |
|---|---|
| 累積報酬 | 最終時間加權指數減 1 |
| CAGR | 依實際經過日數年化的複合報酬 |
| 年化波動 | 每日報酬樣本標準差乘以 $\sqrt{252}$ |
| Sharpe | 年化超額報酬除以年化波動 |
| Sortino | 年化超額報酬除以下檔偏差 |
| 最大回撤 | 報酬指數相對歷史高點的最深跌幅 |
| Calmar | CAGR 除以最大回撤絕對值 |
| VaR / CVaR | 每日歷史分配的 5% 分位數與尾端平均 |
| Beta / Alpha | 與基準日報酬的 OLS 關係 |

## 實質報酬

啟用後，以 FRED `CPIAUCSL` 美國都市消費者物價指數將時間加權報酬折算為實質報酬：

$$
I_{real,t}=\frac{I_{nominal,t}}{CPI_t/CPI_0}
$$

目前不論基準幣別皆使用美國 CPI，非 USD 結果會附上明確警告。這代表「相對美國消費籃子的購買力」，不等於台灣本地 CPI 實質報酬。

## 進階分析

- Fama–French：以 Kenneth French 月資料估計五因子加動能回歸，至少需要 24 個重疊月份，僅提供 USD 基準。
- 風格分析：以六檔美股 ETF 作為大型／中型／小型與價值／成長代理，係數限制為非負後正規化；這不是持股式 Morningstar Style Box。
- 市場環境：多空以基準十個月移動平均分類；波動以滾動十二月波動中位數分類。
- 通膨與景氣：使用 FRED CPI 與實質 GDP，需設定免費 FRED API key。

## 主要限制

1. Yahoo Finance 與 yfinance 適用於個人研究，資料可能延遲、缺漏或事後修正。
2. 回測沒有模擬流動性、成交衝擊、稅負、基金費用率與預扣稅。
3. 現存標的資料帶有存活者偏誤，退市證券不一定可取得。
4. 代理 ETF、因子與總經資料的發布時間未用於交易訊號，因此不可把環境分析解讀為可即時交易策略。
5. 歷史績效不代表未來結果；本站不提供投資建議。
